# 📚 Book Recommendation App

Application web de recommandation de livres développée avec la stack MERN.

## 🚀 Phase 7 — Déploiement et mise en production

### 🎯 Objectif

Déployer et tester l'application dans un environnement de production.

### 🛠️ Technologies utilisées

- React.js
- Node.js
- Express.js
- MongoDB Atlas
- Mongoose
- Axios
- JWT
- Git & GitHub
- Render

### 🔧 Déploiement du Backend

Le backend Node.js / Express a été déployé sur Render.

**Backend URL :**

https://book-recommendation-app-b9z0.onrender.com

L'API est accessible avec le préfixe :

https://book-recommendation-app-b9z0.onrender.com/api

### 🗄️ Base de données

La base de données MongoDB Atlas est utilisée en production.

MONGO_URI
